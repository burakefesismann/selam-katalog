# İçerik Paketleri

Beyin takımının hazırladığı ürün içerikleri buraya gelir. Her paket ayrı klasör:

```
icerik-paketleri/
  001-firat-baumit/
    markalar/...
    kategoriler/...
    urunler/...
    gorseller/...
    NOTLAR.md   ← paketin kaynakları, teyit bekleyen bilgiler
```

Format: `docs/ICERIK-SEMASI.md` (F1.3'te oluşturulur).
İçe aktarma: `npm run icerik:aktar -- <paket-klasörü>` (F3.1'de oluşturulur).
Paketler içe aktarıldıktan sonra burada arşiv olarak kalır.
